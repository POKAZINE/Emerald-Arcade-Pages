# Emerald Arcade

制作者：POKAZINE。ChatGPT・Claude・Geminiと、コピー＆貼り付けで遊ぶ18ゲーム集です。APIキーやアカウント登録は不要です。各AIサービスのチャットは利用者が別途開きます。

## 現在の状態

ローカルで公開準備中です。このファイルの作成時点ではGitHubへのアップロード・公開を行っていません。公開候補リポジトリは https://github.com/POKAZINE/Emerald-Arcade-Pages 、通常の予定URLは https://pokazine.github.io/Emerald-Arcade-Pages/ です。実際のURLはGitHub Pagesの設定で確認してください。

## 遊び方

1. ゲームを選び、「チャットAIと遊ぶ」で相手のAIを選びます。
2. 「状況文をコピー」を押し、AIのチャットへ貼り付けて送信します。
3. AIの返答JSONをゲームへ貼り付け、「返答を反映する」を押します。
4. AIの手番が続く場合は最新状況を送り直します。自分の手番は盤面で操作します。

練習ボットはAIアプリなしで遊べます。

## 記録と秘密

対戦記録と設定はこのサイトを開いたブラウザのIndexedDBに保存します。同じブラウザを共用する人は記録も共有します。端末・ブラウザ間の自動同期はなく、ブラウザデータの削除などで記録を失う場合があります。URLが変わっても自動移行しません。

AIの手札・答え・配置などは状況文や返答JSONに含まれる場合があり、人間から完全に隠せません。ゲームからAIサービスへ自動送信はしません。利用者がチャットへ貼り付けた内容は、そのAIサービスへ送信されます。

## 開発・公開

- 配信対象はdist。HTML/CSS/JavaScriptだけで動作します。
- Node.js 22.13以降でnpm run checkを実行し、構文とモジュール参照を検証できます。追加パッケージは不要です。
- 公開前に個人用GitHubアカウント、対象リポジトリ、予定URLを確認してください。
- 公開を許可した後に、Settings → Pages → SourceをGitHub Actionsへ設定します。
- Actionsの「Publish GitHub Pages (manual)」を手動実行すると公開します。pushだけではこのワークフローは起動しません。
- 画像・スクリプトは相対パスで参照し、リポジトリ名付きのサブパスに対応します。

18ゲームの全設定・全展開を実際のAIアプリで検証したものではありません。ルール処理・AI操作反映・ブラウザ保存はローカルで検証しています。
